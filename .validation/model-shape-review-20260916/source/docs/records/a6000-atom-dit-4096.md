# A6000 ordinary atom DiT — 4096 atoms

The ordinary atom DiT uses the same full pair-bias augmented-attention plus
ConditionedTransition algorithm as token DiT, with two residual additions.
It is distinct from the windowed, RoPE-based SWA-DiT. Earlier consolidated tables
omitted this complete atom block while including its attention component.

One physical RTX A6000, UUID `bc3980f1-1475-227c-c59a-6577004dbe97`, job 1678318.
4096 atoms (the runner's base seq_len=512 multiplied by 8), batch1, depth1,
d_single=d_cond=128, d_pair=16, four attention heads. BF16 inputs and module
parameters under the native bf16-mixed policy (normalization affine stays FP32),
TF32 OFF, mask probability .125. Actual torch.compile execution is verified.
Inference: augmentation5, manual CUDA Graph replay. Training: augmentation48,
CUDA Graph OFF, forward+backward including single/condition/pair and parameter
gradients, no optimizer. These modules have no dropout.

The repository's native module constructors, compile wrapper and measurement function
are used. Each implementation/mode runs in its own process; the table is the median
of three native timing samples within that process. All four processes run sequentially
on the same card. Compilation, warmup and graph setup are outside the timed interval.
Inputs and model initialization use seed0, and actual input shapes are asserted.
MiniWorld cache misses abort; tile caches remained unchanged. The PyTorch reference
performed no MiniWorld autotune lookups. All four results share one measured source hash.

147 module contract regression tests passed, including the new atom dimensions,
full pair-bias block class, pair gradient, depth, precision and compile/mode setup.
The native measurement checks finite outputs/gradients and compile/graph execution;
this run does not claim an additional independent full-module numerical certification.
