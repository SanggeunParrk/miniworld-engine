# Pairformer pair-track latency — B200 (sm100)

Generated by `benchmarks/runners/pairformer_compare.py` (3-way: pytorch / cuEquivariance / ours).
`pairformer_compare.py` is not part of the Hydra `bench.py` harness, so these are recorded here as
a markdown table rather than a CSV/SVG artifact.

- **Config:** B=1, d_pair=128, n_block=4, bf16, CUDA graph, **`--compile` (canonical)**, p_drop=0.25.
- **sm100 notes:** transition CUDA-b2b disabled (Hopper build unsupported) → triton-family path
  (uses the sm100 `gatebwd_sm100` backward); triangle-attention gate forced non-fused for graph capture.
- Times are the per-block-stack median (ms); `ours vs X` = X/ours (>1 = ours faster).
- Inference runs `--compile` cleanly after `4a8ab0a` (`@torch.compiler.disable` on the cute inference
  paths); compile is inert for inference (eval = no dropout/residual to fuse), so the numbers match the
  cudagraph no-compile path.
