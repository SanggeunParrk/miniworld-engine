# The 5I28 benchmark

The model-level speed benchmark: FoldForge on this engine against each model's Anthropic kit (and the vendor's stock code) on
5I28 (azurin, 128 residues), one H100 80GB. Results go to `docs/records/` as dated records; a number taken any other way is not a
5I28 benchmark number.

## Inputs (both sides, every model, every n)

- **Size:** n identical chains, n = 1, 2, 4, 8, 12, 16 (128 n tokens).
- **MSA:** the real MSA, always. FoldForge: `msa_db: ~/data/BioMolDB_20260224/a3m_16k.lmdb`, key `P0113359` (6790 rows); kits: the
  same rows as an a3m. There is no run without the MSA.
- **Templates:** 4 distinct real templates, always: `5SYD_A`, `6KOL_A`, `5YT7_A`, `6TFD_A`.
  - FoldForge: `template_db: .../template.lmdb`, key `P0113359`, `template_n: 4`. The LMDB stores every chain of an entry (20
    records, 6 distinct sequences), and `load_templates` keeps one per hit sequence.
  - Kits: those 4, in each kit's own input form. For Protenix-family kits (Protenix v1/v2, OpenDDE), use the whole 20-hit a3m;
    their search keeps one hit per sequence. Never pass a list that a kit's dedupe would shrink.
  - A kit run counts only when its log shows 4 real templates, e.g. `real=4/4` or `Found 4 templates`.
  - RoseTTAFold3 takes one coordinate set per chain: the same single template on both sides.
  - ESMFold2 has no template input.
- **Sampling:** 4 recycles, 200 steps, 5 samples, bf16. The same seeds are used where the kit allows.

## Timing

One complete model forward:
- trunk passes, diffusion sampler and confidence heads
- CUDA-synchronized before and after
- excluding featurization, loading and output writing

Report the median of the warm forwards; the first forward is cold.
- FoldForge: `model_seconds_warm`.
- Kits: their `PHASE ... fwd_s` (or the kit's equivalent span, per the kit fwd-definition audit
  `docs/records/anthropic_kits_fwd_definition_audit_20261029.md`). Do not use the kits' wider "Model forward time" lines.

FoldForge runs on prebuilt kernels and warm caches. No JIT compile inside a timed run.
