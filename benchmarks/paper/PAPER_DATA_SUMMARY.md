Cards found: H100, A100, RTX 5090. A B200 CSV set is picked up automatically when it is present (re-run the script).

## 0. Conventions

- Ratio = `other / engine cuda` of the same case (same requirements row, variant, L, depth, samples, dtype, mode); ratio > 1: the engine is faster. Only `status == ok` rows enter. Speedups are geometric means with `[min-max]` over the paired cases, last number = number of cases.
- Backends: `pytorch` (eager reference, engine stack), `triton` (the engine's own portable Triton), `cueq` (cuEquivariance, where it serves the class), `anthropic` (Anthropic kernels, kit stack; the engine-stack cuda is paired with the kit-stack row of the same case).
- dtype: `master` = fp32 master weights under bf16 autocast, shown as **bf16**; `float32` = **fp32** (measure/config.py: DTYPES master -> torch.bfloat16). mode `eval` = inference, `train` = forward + backward.
- Timing: CUDA-graph replay median; E1/E2/E3/E6 H100 records 100 iterations, A100 / 5090 mixed 100 / 20, E5 20 (`benchmarks/paper/README.md`, iteration note). Nothing from paper/mac_20261119 is used.
- Operator class = the E1 `module` column (every module of the requirements table).
