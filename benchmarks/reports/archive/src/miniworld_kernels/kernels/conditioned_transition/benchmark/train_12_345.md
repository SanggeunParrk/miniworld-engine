# ConditionedTransition training — 1+2 | 3+4+5 mirrored triton backward — H100, fp32 / TF32

_Autograd Function `cond_transition_train_12_345` / `ConditionedTransitionTail12345Function`:
pairs the 1+2|3+4+5 forward (`cond_transition_fwd_12_345`) with a backward that MIRRORS the
forward grouping (reverse order), fusing the producing elementwise INTO each consuming dgrad GEMM
prologue — the exact structure to drop-in CUTLASS-ify. wgrad on cuBLAS. **Triton-first:
correctness + clean mirrored structure are the deliverable; perf is the reference number
(CUTLASS swap later). Source: `train_12_345.out`._

## Structure (mirror of the forward)

Forward: K1 = 1+2 (expand+SwiGLU→h), K2 = 3+4+5 (squeeze+to_scale+gate→y). Backward, reversed:

**Bwd of K2 (3+4+5)** — `_dh_gatebwd` fuses gate-bwd into the dh dgrad GEMM prologue:
- gate-bwd (in GEMM prologue): `dout = sigmoid(scale)*dy`, `dscale = out*sg*(1-sg)*dy`
- squeeze-bwd: `dh = dout @ Ws` (dgrad, fused) ; `dWs = dout^T @ h` (wgrad, cuBLAS)
- to_scale-bwd: `dcond = dscale @ Wsc` (dgrad) ; `dWsc = dscale^T @ cond` (wgrad) ; `db_sc = dscale.sum(0)`
- emits dout, dscale (materialized) → feeds dcond dgrad + the cuBLAS wgrads.

**Bwd of K1 (1+2)** — `_dx_swiglubwd` fuses swiglu-bwd into the dx dgrad GEMM prologue:
- swiglu-bwd (in GEMM prologue): `da = dh*b*silu'(a)`, `db = dh*silu(a)` (silu'(a)=sa+silu(a)·(1-sa))
- expand-bwd: `dx = dab @ [Wa;Wb]` (dgrad, ONE cat-merged GEMM) ; `dWcat = dab^T @ x` (wgrad, cuBLAS) → dWa,dWb
- emits dab (materialized) → feeds the cuBLAS dWa/dWb wgrad.

Forward saves **ab=[a|b], out, scale** (NOT h — h is freed after K2 and recomputed from ab in bwd).
dgrad GEMMs = fused-elementwise triton (TF32, the CUTLASS-able structure); wgrad = cuBLAS
(M-reductions). Uniform for atom (d=128) and token (d=768).
