# A100 (sm80)

Cluster: cssb. Partition `A100` (the default), nodes `gpu01`-`gpu09`, 4× A100 80GB PCIe each; no `--account`
needed, QoS `normal` by default (`interactive`, `low` also exist). Driver 570, so CUDA ≤ 12.9.

```sh
sinfo -p A100 && squeue -u "$USER"
# CPU-only (pixi install, lint, CPU tests)
srun -p A100 --gres=none -c 8 --mem=32G --time=01:00:00 <cmd>
# one GPU
srun -p A100 --gres=gpu:A100:1 -c 8 --mem=64G --time=00:30:00 \
  bash -c 'pixi run --frozen bash -c "export LD_LIBRARY_PATH=\$CONDA_PREFIX/lib:\$LD_LIBRARY_PATH; \
  export MINIWORLD_ENGINE_JIT_ROOT=\$HOME/.cache/miniworld-engine-jit/a100-sm80; <cmd>"'
```

Setup: `pixi install`, `pixi run fix-te-cu12`, `miniworld-engine dev install-flash --arch sm80` (installs
FlashAttention-2 2.8.3, a prebuilt wheel was found in the pip cache).

Paired Anthropic comparison before optimization, 2026-10-04: [all measurements (CSV)](anthropic-compare-20261004.csv),
[speed ratios (figure)](anthropic-compare-20261004.png),
[raw rounds, accuracy and executed kernels (JSON)](anthropic-compare-20261004.json).
The experiment covers 29 public module families at actual attention lengths 128/384/768,
BF16 inference, identical nonzero weights and inputs, no TF32, and CUDA Graph replay.
Each pair shares its GPU and alternates order over nine rounds; compilation and packing
are excluded. MiniWorld's optional Anthropic TriMul override is disabled for the MiniWorld
calls and checked against executed selections. These are module latencies, not isolated
kernel latencies or whole-model speedups. Atom lengths denote atoms, not eight times a
token count; token augmentation is 2, MSA depth 64, and pair width 128 (post-normalized
OPM output 256). SWA uses two fully valid sequences and a half-window of 64. Pairformer
self-attention explicitly uses `block:triattn_native`, matching the standalone TriAttn
comparison; its slower legacy `k2b` default is kept separately in the raw record.
The separate frozen-weight Transition experiment measures forward plus
input gradient at C256/H1024, without parameter gradients. Runners:
`benchmarks/runners/compare_anthropic_a100.py` and `compare_anthropic_backward_a100.py`.

All 87 inference cells pass accuracy and graph replay checks. With a 5% speed band,
MiniWorld leads in 80 cells, five are within the band, and Anthropic leads in two
(conditioned transition L128 and ending TriAttn L768). At L384 the native-core
Pairformer block is 2.339 ms vs 2.755 ms (1.18×); token DiT is 0.135 ms vs 0.341 ms
(2.52×). The original frozen-weight `esm_kd3` forward+input-gradient row is 1.09–1.13×
faster than MiniWorld at the three tested lengths; the lean and T15 compositions
do not share that advantage. These comparisons use the connected qualified rows,
not an exhaustive search of every upstream variant.

Ratios above 1 favor MiniWorld. The two large TriangleAttention rows remain within
the 5% parity band; their small median advantage is not a decisive lead. Before and

rounds on the same GPU. An additional same-process dense-versus-compact comparison
measures a 1.077× / 1.079× improvement for starting / ending TriangleAttention
(3.726→3.458 ms / 3.783→3.501 ms), including runtime mask and bias packing.

The changes are a frozen-parameter input-gradient path that omits two weight-gradient
GEMMs, a row-kernel/cuBLAS dispatch for BF16 atom ConditionedTransition with at most
4096 rows, and 48-key attention tiles with stable GPU key compaction for masked
inference at L≥768 divisible by 384. The latter indexes K/V in place, gathers only
the bias planes, and keeps the stable online softmax. Training retains the dense
attention core; `MINIWORLD_TRIATTN_SM80_COMPACT=0` selects it for inference too.
This performance result uses the comparison's mask (every seventh key excluded);
it does not establish a lead for every possible length or mask density.

generate surrounding copy/gradient-bookkeeping kernels.

SOL90 follow-up, 2026-10-04: **the four-family SOL90 target is not achieved.**
The accepted changes keep BF16 weight-gradient GEMMs on tensor cores with FP32
accumulation/output, vectorize the general CUDA elementwise kernels, connect
shared-conditioning Token DiT and ConditionedTransition training to the existing
CUDA compositions, and select row/cuBLAS ConditionedTransition training through
16384 rows. Larger atom training inputs retain the fused kernels. The full
forward/backward/fake-op branches use the same threshold.

Same-process BF16 comparisons against the preceding CUDA coverage version:
shared-conditioning Token DiT training is **2.22× / 3.95×** faster at L128/768;
ConditionedTransition training is **2.80× / 2.66×** faster. These fixtures use two
samples and one shared conditioning tensor. General attention training also
improves through the tensor-core weight gradients and vectorized row passes;
these are latency improvements, not SOL percentages. The standard large
per-sample training paths are a separate measurement:

| BF16 training path | Geometry | Current composite SOL |
|---|---|---:|
| Token DiT | A48, L384 / L768, D768 | 82.0% / 80.8% |
| ConditionedTransition | A48, L3072, D128, cond128 | 60.7% |
| TriMul, outgoing | B1, L384 / L768, D128 | 69.2% / 74.2% |
| TriangleAttention, starting | B1, L384 / L768, D128 | 52.9% / 53.1% |

SOL here uses the existing decomposition floors and the historical measured
ceilings of 1.60 TB/s and 240 TFLOP/s. It is not an exhaustive FP32/shape audit.
The standalone BF16 gate/SwiGLU row passes reach approximately 1.65–1.69 TB/s at large
sizes; values above 100% against the old empirical denominator indicate that
the ceiling needs recalibration, not physically super-peak throughput.
This does not establish whole-module SOL90.

Nsight counter captures and 32 schedule comparisons locate remaining work in
TriMul's joint backward and TriangleAttention's backward cores. None of the
schedule alternatives gave a material improvement. The D128 wide TriMul path
was slower, and combining attention projections increased large-input copying;
both alternatives were rejected. **239 distinct GPU tests passed**, including
shared-conditioning input/parameter gradients, both sides of the training
dispatch threshold, unaligned vector tails and fullgraph compilation; Ruff and
scoped type checks pass. Raw paired rounds, SOL accounting, profiler metrics,
rejected candidates and scripts: [SOL90 progress report](sol90-progress-20261004.json).
