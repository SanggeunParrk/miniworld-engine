## Completion status

Facts as of 2026-09-28 (v2.2.0). Rules: [README](../README.md#completion-tables).

A100 runs Triton everywhere except the fused sm_80 Transition (D128, n=4, bf16), the only
sm_80 hand-CUDA path wired into dispatch. A tuned cache exists
(`src/miniworld_engine/autotune/data/*/NVIDIA A100 80GB PCIe (sm80).json`, 72 ops) but it
was built under torch 2.10 / triton 3.6 and is stale on the 2.2.0 environment until rebuilt.
The six `sm80 cuda` registry rows are native LayerNorm/norm kernels.
