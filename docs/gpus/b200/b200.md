# B200 (sm100)

NVIDIA B200 × 8 (148 SMs, 183 GB each), sm_100a, driver 580.95.05. The cards sit in a
container on a lab-external server, **not** in a cssb Slurm partition: there is no scheduler,
the GPUs are shared with other users, and access details are kept outside this repository.

- **Check the card is yours before every measurement**:
  `nvidia-smi --query-compute-apps=pid,process_name,used_memory --format=csv -i <gpu>`.
  Another process on the same GPU silently contaminates timings.
- **Environment**: the repo's pixi env installs and runs as-is (the 580 driver runs the cu129
  build): `pixi install --frozen`, `pixi run --frozen fix-te-cu12`,
  `pixi run --frozen miniworld-engine dev install-flash --arch sm100` (FA4 4.0.0b32).
- **Keep every cache on persistent disk**: `/tmp` is a tmpfs (RAM) and the home directory is
  container-local. Point `TMPDIR`, `PIXI_CACHE_DIR`, `RATTLER_CACHE_DIR`, `UV_CACHE_DIR`,
  `TRITON_CACHE_DIR`, `TORCH_EXTENSIONS_DIR` and `MINIWORLD_ENGINE_JIT_ROOT` at the shared
  workspace.
- **Power cap**: 1000 W per card. Under sustained load the SM clock settles near 1.89 GHz, so
  bandwidth- and tensor-bound kernels are limited by energy before they reach the datasheet
  rates.
- **Profiling**: the driver sets `RmProfilingAdminOnly=1`; `ncu` needs root on this machine.
  `ncu` also locks the SM clock (~930 MHz): compare cycles, not times.
- **cuEquivariance 0.12** ships sm_100a images in the cu12 wheel. Its B200 TriMul route is
  inference-only and admits hidden 256 with d_pair 256 / 384 / 512; D128 runs its generic path.
- **nvcc for the fused Transition**: its kernels are built by the newest nvcc that knows sm_100a
  (`/usr/local/cuda-13.1` on the B200 box); CUDA 12.9's ptxas makes its backward ~8 % slower.
- Completion per shape: [below](#completion-status).

## Completion status

2026-09-29, v2.2.0 + `b200/trimul`, torch 2.13.0+cu129 / triton 3.7.1. B200 = CUDA where a
hand-written sm_100a path exists; a shape without one is 미구현 (it runs the Triton path).
TriMul / TriAttn: bf16 only, columns are (Length, Dimension). 성능 확인 = maintainer.
cache build ✓ = usable on this toolchain with nothing left to tune (the CUDA path has fixed
schedules and cuBLAS contractions); no B200 Triton cache exists yet.
