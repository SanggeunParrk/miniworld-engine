# H100 (sm90)

Cluster: cssb, partition `h100`, account `cssb`. Nodes `node01`/`node02`, 8× H100 80GB HBM3
(132 SMs) each. Driver 575, so CUDA ≤ 12.9 (cu130 wheels do not load). QoS `normal_h100`
(priority 100, preemptible) or `cssb_h100` (priority 1000); use `normal_h100` unless told
otherwise and at most 4 GPUs at a time.

```sh
sinfo -p h100 && squeue -u "$USER"
# CPU-only (install, lint, CPU tests, derive of the plan without GPU work)
srun -p h100 -A cssb --qos=normal_h100 --gres=none -c 8 --mem=32G --time=01:00:00 <cmd>
# one GPU
srun -p h100 -A cssb --qos=normal_h100 --gres=gpu:h100:1 -c 8 --mem=64G --time=00:30:00 \
  bash -c 'pixi run bash -c "export LD_LIBRARY_PATH=\$CONDA_PREFIX/lib:\$LD_LIBRARY_PATH; <cmd>"'
```

- `/home` is NFSv3 on compute nodes; JIT build locks are NFS-safe since 2.2.0.
- Nsight Compute needs counter permission; `ERR_NVGPUCTRPERM` means use nsys / CUDA events.
- Prebuilt TriangleAttention `.so` (in `src/miniworld_engine/kernels/triangle_attention/cuda/`)
  must match the env's torch and python; rebuild with
  `python -B ~/miniworld-engine-scratch/v220-env/triattn_rebuild.py --workers 4` (local scratch script, not in the repo) on a CPU allocation with
  `CUTLASS_PATH` set (CUTLASS 4.2 headers).
- Module dispatch on H100 (which op takes which CUDA path, contracts, saved tensors):
  [h100-dispatch.md](h100-dispatch.md). Completion per shape: [below](#completion-status).
- Historical rented-H100 (Vast) workflow: records/h100/vast-h100-20260927.md (`archive/records-20260928:docs/records/vast-h100-20260927.md`).

## Measurements (2026-09-28)

Record, not updated after the fact. Cluster `h100` partition, H100 80GB HBM3 (132 SMs),
torch 2.13.0+cu129, triton 3.7.1, bf16 pair tensors, fp32 LayerNorm affine, B=1.
**Triton autotune caches were stale** (built under torch 2.10 / triton 3.6), so every Triton
baseline below ran on its heuristic config subset; a rebuilt cache may speed Triton up.

### TriMul — CUDA vs Triton, manual CUDA graph, paired alternating replays, median (ms)

Triton = `engine_backend="triton"`; CUDA = default `auto` dispatch, path proven by counting
entry-point calls. Error of the update vs an fp32 PyTorch module ≈ 0.0064–0.0067 for CUDA
(Triton 0.0062–0.0064); changed-input graph replay exact.
