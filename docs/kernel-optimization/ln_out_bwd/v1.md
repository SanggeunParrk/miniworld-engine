# LN_out backward (te_style `_ln_bwd_kernel`) — v1: m-major-specialized atomic-free persistent

**Target:** trimul LN_out backward, previously te_style `_ln_bwd_kernel` (Triton, atomic dγ/dβ).
**GPU:** NVIDIA B200 (sm_100), torch 2.10.0+cu128, 8×GPU.
**Kernel dtype:** bf16 in / fp32 acc+stats / bf16 out. Precision unchanged.

## Layout
LN_out operates on `(M, N)` tensors that are **m-major**: features N have stride M, the M tokens
are unit-stride (contiguous). `dx_normed`, `x`, `dx` all share strides `(1, M)`.
- single-dir LN_out: N = D = 128, M = L·L.
- bidir LN_out: N = H = 2·d_hidden = **256**, M = L·L.

## Bottleneck (te_style atomic kernel)
ncu (prior): mem-pipe ~40% / occ ~30% / DRAM ~8% — far from HBM roofline. Cause: `atomic_add(DG/DB)`
once per tile per feature → ~cdiv(M,BLOCK_M) atomics onto N (128/256) L2 lines = contention.
Also: routing the standalone N-contiguous CUDA LN kernel here is a **4–13× net loss** (measured):
m-major → `.contiguous()` transpose copies dominate (catastrophic at L=1024).

## Change (lessons applied, no algorithm change)
New `layernorm_linear/mmajor_bwd.py`:
1. **Atomic-free dγ/dβ**: persistent grid of `NUM_SM*2` CTAs grid-strides over M-tiles, carries
   dγ/dβ in fp32 **registers** across the whole stride loop, writes ONE partial row each →
   partial buffer `[G, N]` (~296 rows); tiny final reduce. Zero atomics.
   (= layernorm module's `_bwd_persistent` pattern, generalized to the m-major stride pair.)
2. **M-contiguous vector loads**: `tl.max_contiguous/multiple_of` on the row index + compile-time
   unit row-stride → wide loads along the contiguous M axis.
3. Size-adaptive dispatch (`ln_bwd_mmajor`), all bit-exact:
   - small M (< 300k) → te_style atomic (persistent grid underfilled there);
   - large M, N≤128 → this module's specialized kernel (vector hint wins);
   - large M, N>128 → canonical layernorm persistent kernel (wins at wide N).
   Env `MINIWORLD_LNOUT_BWD=atomic|persistent|canonical` forces a path (A-B/debug).
`te_style._ln_bwd` delegates to `ln_bwd_mmajor` (deferred import breaks the module cycle).

## Validation — bit-exact
Standalone dx/dγ/dβ cos = 1.00000 vs atomic. Full-graph replay (both harnesses, all L):
**worst_cos = 1.000000** (grads bit-exact vs eager). Math/precision unchanged.

## Performance
### Standalone `_ln_bwd` (shipped vs atomic), do_bench median, B200
| shape | atomic | shipped | speedup |
|------|-------:|--------:|--------:|
| N=256 L768  | 382.0 µs | 326.5 µs | 1.17× |
| N=256 L1024 | 689.3 µs | 570.6 µs | **1.21×** |
| N=128 L768  | 169.0 µs | 155.7 µs | 1.09× |
| N=128 L1024 | 302.1 µs | 248.9 µs | **1.21×** |
| N=* L384    | — | — | 1.00× (atomic fallback, M<300k) |

### E2E training graph-time — same-time A-B (OLD atomic vs NEW), all worst_cos=1.0
| config | OLD atomic | NEW | speedup |
|-------|----------:|----:|--------:|
| single L768  | 2.1064 ms | 2.0632 ms | 1.021× |
| single L1024 | 3.7617 ms | 3.6901 ms | 1.019× |
| bidir  L768  | 3.3914 ms | 3.3109 ms | 1.024× |
| bidir  L1024 | 6.2607 ms | 6.1742 ms | 1.014× |
L=384: NEW == baseline (atomic fallback; no regression).

Net e2e win 1.4–2.4%, consistent direction across all 4 configs, measured same-time (drift-controlled).

## Next ideas

  matters most at small M where it currently forces the atomic fallback).
- Unify N=128/N=256 into one kernel (the N=256 config the canonical kernel finds is not the one
  this module's autotune lands on — investigate the config/codegen difference).
