## 2. Auto-dispatch (commit 467b1ca)
New modules/triangle_multiplication/dispatch.py (env override -> static arch heuristic, per
docs/operations/dispatch-cache.md). The trimul choice is an ARCH CAPABILITY dispatch (tcgen05 vs
quack), not a shape crossover, so a static arch heuristic is the policy (no per-shape cache):
- resolve_impl(MINIWORLD) -> CUTE on Hopper+ (sm_90/sm_100), TRITON otherwise.
- resolve_out_layout() -> "bdll_sm100" on sm_100 (B200, our tcgen05), "bdll_direct" otherwise (H100).
- env: MINIWORLD_TRIMUL_IMPL, MINIWORLD_TRIMUL_OUT_LAYOUT.
module.py + bidirectional.py: __init__ resolves 'miniworld' -> concrete impl; _forward_cute uses
resolve_out_layout(device) (restores main's bdll_direct on H100 -> fixes CUTE on H100; keeps our
tcgen05 on B200). single-dir _forward_cute gained incoming-direction support (bdki,bdkj einsum).
