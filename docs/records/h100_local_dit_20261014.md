Tuning after the matrix: samples per attention CTA 8 -> 16 (dkv 354 -> 295 us bf16, 458 -> 384 fp32), `__launch_bounds__(.., 3)` for the bf16
`cond90` / `cond_bwd90` (278 -> 267, 292 -> 258 us), two warpgroups for the fp32 `tr_bwd90` (565 -> 491 us). Tried and dropped: TMA ring
(persistent or not), producer warp / `setmaxnreg`, coalesced bias-band build for dkv (fp32 384 -> 417 us), min-3 CTAs for `post_bwd90` /
`pre_bwd90` (spills, 417 -> 496 / 330 -> 567 us). Final matrix minimum ratio 0.99 (fp32 training A1 N128, outside the required shapes).
