# MiniWorld Engine 2.0.0

Previous declared version: **1.0.0**. This release consolidates development after
Anthropic's published kernels, including independent research branches, while
preserving their history. See the [changelog](../../CHANGELOG.md) for API removals.

## Credit and approach

We developed inference kernels, but Anthropic's published results were better.
We respect and build on that development. Our addition is integration and
training-capable adaptations, with numerical checks and measured limitations.
[Attribution and license](../../THIRD_PARTY_NOTICES.md).

The research capsule isolates its older benchmark engine. It does not replace
`src/miniworld_engine` or change the installed engine's default TriMul training
path. Its dates are experiment provenance, not additional release versions.

## Validation and limits

- Original records include all eleven gradients over ten shapes, graph replay,
  live-input/weight changes, repeated autograd forwards and version checks.
- Strict D128 same-formula LN limits remain 5e-6; cross-implementation BF16
  checks use separate output/gradient limits. They are not interchangeable.
- Original memcheck/racecheck evidence covers wide L384 and modified D128 L768.
- The capsule requires a full H100, one visible GPU per process, B1, BF16,
  L384/768 and explicit dropout scales; it is not a general production API.
- Single-launch B7 still uses global scratch. Tensor-pipe/L2 utilization is not
  algorithmic SoL; this release makes no SoL90 claim.
- Release revalidation is recorded in `verdicts/release-2.0.0.json`.

## Reproduce

Install the engine dependencies and CUDA 12.9 toolchain, allocate an H100, then:

```bash
bash experiments/trimul_training_v2/env.sh python -B \
  experiments/trimul_training_v2/verify_release.py --index 2
```

Indices 0–9 enumerate D64/128/256/384/512 crossed with L384/768. Build products
are local and excluded from Git. See the capsule README for historical scripts.

Invalidated runtime records: [27 archived caches](../records/release-2.0.0/retired-caches/README.md). These were not retuned for this release.

### Transition dispatch migration

The new `transition_fused_sm90a` switch takes precedence inside the residual
path. To compare an entirely Triton Transition with CUDA, disable it explicitly
(`settings.configure(engine_backend="triton", transition_fused_sm90a=False)`;
its environment override is `MINIWORLD_TRANSITION_FUSED_SM90A=0`). Pinning only
`engine_backend` does not disable this new path. The legacy split-path policy
has a separate regression test.
