# A100 (sm80) — completion status

Environment: [docs/gpus/a100.md](../gpus/a100.md) · rules for this page: [README](README.md).
Facts as of 2026-09-28 (v2.2.0).

A100 is a Triton-only target: every hand-CUDA path in this repo is sm90-gated, so the
Triton family serves every op. A tuned cache exists
(`src/miniworld_engine/autotune/data/*/NVIDIA A100 80GB PCIe (sm80).json`, 72 ops) but it
was built under torch 2.10 / triton 3.6 and is stale on the 2.2.0 environment until rebuilt.
The six `sm80 cuda` registry rows are native LayerNorm/norm kernels.

The **judgement** column is the maintainer's.
