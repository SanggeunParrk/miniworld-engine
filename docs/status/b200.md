# B200 (sm100) — completion status

Environment: [docs/gpus/b200.md](../gpus/b200.md) · rules for this page: [README](README.md).
Facts as of 2026-09-28 (v2.2.0).

v2.2.0 removed the CuTe DSL kernels that were the only sm100-specific code; nothing in
`kernels/registry/registry.csv` declares sm100. Hand-CUDA B200 kernels are being developed outside
this repo. Every op below therefore runs its **Triton** (sm80+) path on B200, and the sm90
hand-CUDA kernels are not selected (their dispatch checks compute capability 9.0).
No B200 autotune cache exists (`src/miniworld_engine/autotune/data/*/` has no sm100 file).
