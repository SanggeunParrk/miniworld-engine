# Experiments

This directory is for one-off probes, diagnostics, profiling scripts, discarded
kernel variants, and migration notes that should not be importable package code.

Files here may be useful research history, but they are not part of the public
`miniworld_kernels` package surface and should not block strict linting of
library code.

When an experiment becomes a supported benchmark, move it into
`benchmarks/suites/` and keep only the final report in `benchmarks/reports/`.
