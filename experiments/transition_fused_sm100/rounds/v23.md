## 3. Bug: weight-role CTAs without a tile wrote uninitialized partials

With fewer 128-row tiles than weight-role replicas (`tiles < R`, i.e. fewer than 9 tiles at R = 9), the replicas that own no tile
signal `wg_done` without ever accumulating, and the partial write-out read tensor memory that was never written: dWa / dWb / dWs came
out wrong (relative error 0.7 in the engine test at 128 rows) whenever that memory was not zero. Every capsule benchmark ran
L ≥ 128 (≥ 128 tiles), so it never showed. Fix: such a CTA writes zeros. Caught by the engine test
`test_fewer_tiles_than_weight_replicas` (NaN-poisoned allocator), which fails before the fix and passes after.

## 4. ptxas 12.9 vs 13.1

Wiring the kernels into the engine first built them with the engine's nvcc (12.9, the toolkit torch cu129 pins). The same `tbwd.cu`,
same flags, alternating in one process (`tr_ab.py`):

| backward | nvcc 13.1 | nvcc 12.9 |
|---|---:|---:|
| L384 | 230-234 µs | 248-251 µs |
| L768 | 881-904 µs | 990-992 µs |

The 12.9 build has a different schedule (4624 vs 4736 SASS lines, 272 vs 288 B stack) and is ~8 % slower; the forward is within noise
at L384. The engine therefore builds the two kernels into cubins with the newest nvcc that knows sm_100a and loads them through the
driver API (`kernels/transition/cuda/fused_sm100a.py`, branch `feat/transition-sm100a`).
