# transition_fused_sm100 — widths round w4: the no-recompute wide path, tuned (D = 384 / 512 faster than torch.compile)

- Date: 2026-09-29. User: "faster than torch.compile, no matter what"; the fp32 recompute of a / b may be dropped. B200 GPU 7, L384 unless noted.
- Run-to-run noise on this card is ~+-10 % for the same kernel across processes (cuBLAS dWab 475-618 us); decisions below come from repeated runs.

## 1. Path (D = 384 / 512)

forward : `tln_w` (16 lanes per row at D <= 384, 32 at 512) -> `tswiglu_w -DSAVE_AB` (writes h, a, b; one store thread and staging per
          warpgroup) -> `tgemm_nd` EPI_RESID
backward: `tgate_ab -DNO_H` (dh = bf16(dy Ws) on tcgen05 fused with the gate from the saved a, b; dA over a and dB over b in place; a / b
          double-buffered per epilogue warpgroup; the forward's h is kept, so no h store) -> cuBLAS dWs = dy^T h, [dWa; dWb] = [dA|dB]^T xn
          (fp32 out) -> `tgemm_nd` EPI_PLAIN d_xn -> `tlnbwd_w` (16 / 32 lanes per row, three inputs loaded up front)

Accuracy vs the fp32 module, 384 / 1920 rows and L384 / L768: out 2.2-2.3e-3, dx 3.3e-3, dWa / dWb 3.9e-3, dWs 2.9e-3 (the forward's h,
computed from fp32 a / b), dgamma / dbeta 3.4-4.4e-3 -- all below PyTorch's own bf16 module (3.3e-3 / 4.1e-3 / 5.3e-3 / 5.3e-3 / 5.0-5.9e-3);
bit-reproducible. Activation memory: xn, h, a, b per layer (a and b are what torch.compile keeps too).

## 2. Steps that moved it

| change | effect (D384 / D512, L384) |
|---|---|
| fused dh GEMM + gate (`tgate_ab`, single a/b buffer) | gate 621 / 841 vs cuBLAS dh + elementwise 587 / 845: nothing |
| a / b double-buffered per warpgroup (MMA ring 2) | 542 / 757 |
| keep the forward's h (no h staging / store) | 430 / 617; dWs error 3.9e-3 -> 2.9e-3 |
| + 3-stage MMA ring (room freed by the h staging) | 352-405 / 531-579 |
| LayerNorm forward 16 lanes per row (32 at D512) | 76 -> 47-60 / 57 -> 52-65 |
| LayerNorm backward 16 lanes per row, loads up front (32 at D512) | 146-212 -> 85-120 / 139-183 -> 105-147 |

Standalone LN kernels at L384 (µs, TB/s): D256 fwd 26 (5.8) bwd 54 (5.6); D384 fwd 47 (4.8) bwd 85 (5.3); D512 fwd 52 (5.9) bwd 105 (5.7).
