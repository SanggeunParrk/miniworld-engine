# LN backward — hand-CUDA row_scale (AF pair-mask) support — v1

**Target:** `layer_norm_bwd_main_kernel` (hand-CUDA vectorized LayerNorm backward,
`src/miniworld_engine/kernels/layernorm/cuda/layer_norm_cuda_kernel.cu`) — the LN_in
backward of the trimul training path (`V6TriMulMergedSm100`), which currently runs the
triton `layer_norm_bwd_dx_fused`.

**GPU / build:** NVIDIA B200 (sm_100), pixi env, bf16, `CUDA_VISIBLE_DEVICES=2`.
JIT build via `torch.utils.cpp_extension.load` with explicit `-gencode` sm_80/90/100.

## Motivation

The hand-CUDA LN backward (`e1fb0b1`, `784e14c`) was tuned to beat the triton persistent
bwd, but it was **dead in the real Pairformer path**:

1. gated OFF by default (`MINIWORLD_LN_IN_CUDA=0`), and
2. gated by `not has_rs` — it had **no row_scale epilogue**, so any LayerNorm carrying an
   AF triangle pair-mask (`y = LN(x) * row_scale`, the production case) was excluded.

Corrected steady-state profile of `V6TriMulMergedSm100` (L=1024, fwd+bwd, cudagraph,
cudaProfilerApi capture) puts LN at ~21% total (cuBLAS ~44%, front ~26%). LN_in bwd alone
is ~7.8%. So this is a targeted, bounded win on the masked path — not the top bottleneck,
but free correctness-preserving headroom that was previously unreachable.

## Change

`y = LN(x) * rs` (rs = per-row mask scalar, a constant — no grad to rs). The entire
backward is the standard LN backward with the incoming grad pre-scaled by `rs[row]`:
`dy' = dy * rs`, then `dx / dw / db` all follow. This is exactly what the triton kernel
does (`dy = dy * rs[:, None]` right after load).

CUDA implementation (one FMA on a warp-uniform register, no divergence):

- `layer_norm_bwd_main_kernel`: new `const float* __restrict__ RS` param (nullptr = plain
  LN); per row `const float rs = (RS != nullptr) ? RS[row] : 1.0f;`; `dy_v = (float)dy_vals[k] * rs`
  in both the `wdy`/reduction loop and the `dx`/`acc_dw`/`acc_db` loop. Because `dy_v` feeds
  `wdy` (→dx, via c1/c2), `acc_dw`, and `acc_db`, one scaling covers dx/dw/db.
- `layer_norm_cuda_bwd`: optional `c10::optional<torch::Tensor> rowscale` → fp32 [M] contiguous,
  passed as `rs_ptr` (nullptr when absent). pybind arg defaulted to None.
- `layer_norm_bwd_cuda(dy, x, weight, mean, rstd, row_scale=None)` python wrapper.
- `TritonLayerNormFunction.backward`: gate relaxed to
  `x.dtype==bf16 and 128<=N<=512 and (has_rs or _LN_CUDA_BWD_ENABLED)` — **auto-take CUDA for
  the masked path** (it always wins, see below), keep dense behind the opt-in env flag (dense is
  neutral/slightly-worse). Lazy import + try/except → graceful triton fallback on any build/run
  failure.

## Validation (correctness)

`test_ln_rs_cuda.py`, L=512, M=262144, N=128, bf16, ~85%-keep row mask, fixed shared inputs
(triton vs CUDA on identical x/w/b/dy — earlier "cos~0" was a harness bug that re-drew inputs
per path):

| case | y cos | dx cos | dw cos | db cos | dx maxabs | dw maxabs |
|---|---|---|---|---|---|---|
| DENSE (no rowscale)  | 1.000000 | 1.000000 | 1.000000 | 1.000000 | 7.81e-3 | 0.0 |
| MASKED (rowscale)    | 1.000000 | 1.000000 | 1.000000 | 1.000000 | 7.81e-3 | 0.0 |

dx maxabs 7.8e-3 = bf16 rounding; dw exact. **Grad-exact.**

## Performance

### Isolated `triton_layernorm` fwd+bwd (M=L², N=128; fwd identical → delta is bwd), triton/cuda:

| L | DENSE | MASKED |
|---|---|---|
| 384  | 0.944x (cuda slower) | 1.026x |
| 512  | 1.002x (tie)         | **1.173x** |
| 1024 | 1.068x               | **1.276x** |

Why masked >> dense: triton's rowscale path is measurably more expensive
(L512 masked triton 0.1320 ms vs dense 0.1046 ms = +26%), while the CUDA rowscale is nearly
free (masked 0.1126 vs dense 0.1044 = +8%, one uniform-register FMA). CUDA erases the triton
rowscale penalty.

### End-to-end `V6TriMulMergedSm100` fwd+bwd, cudagraph, bf16 (masked, [B,L] residue mask):

| L | triton (before) | CUDA (after, default) | speedup |
|---|---|---|---|
| 512  | 0.956 ms | 0.940 ms | 1.017x |
| 1024 | 3.414 ms | 3.318 ms | 1.029x |

Dense e2e **unchanged** (0.926 / 3.318 ms — dense stays on triton). Masked is now at parity
with dense (rowscale penalty gone).

## Result

- ~2–3% e2e on the masked (real AF3) trimul training path; grad-exact; dense untouched.
- Revives the previously-dead tuned CUDA LN bwd for the production masked path with no env flag.
- One-time cost: first masked bwd triggers the nvcc JIT build (~2 min); cached after.
