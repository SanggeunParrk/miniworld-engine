# trimul_bidir_b200 v2 — bidirectional trimul TRAINING (fwd+bwd) on the v9 sm100 kernels

## Goal
Extend v1 (inference) to a save-heavy TRAINING path (fwd+bwd) for the repo's fused
bidirectional trimul, built on the single-direction v9 training kernels, and bench honestly
vs cuequiv on B200.

## Environment
- B200 (sm_100a), GPU 6. Branch `perf/trimul-bidir-b200`, worktree `~/psk/mw-bidir`. B=1,
  d_pair=d_hidden=128, bf16 in / fp32 acc (fp32 LN stats) / bf16 out.

## Composition — `kernels/trimul_inproj/cute/bidir_training_b200.py::BidirTriMulB200Fn`
Faithful bidirectional analog of `training_b200.TriMulB200Fn` (single-dir v9). Save-heavy
forward, manual backward with NO forward recompute. Reused v9 sm100 kernels:
  - front: sm100 tcgen05 gated-GLU collective (`trimul_front_sm100_fused`), per direction
    (outgoing [:h] / incoming [h:], each square (d,h)=(128,128)).
  - front bwd: FUSED `front_gatebwd_sm100` (per direction, x4).
  - LN fwd: fused triton `_ln_fwd_fused` (fp32 stats); LN_in AND LN_out.
  - LN_in bwd + LN_out bwd: arch-agnostic optimized LN bwd (`_ln_opt_bwd`, dispatch-cached).
  - GLU/gate bwd: fused `_glu_bwd`; LLD<->DLL transposes: coalesced tiled triton `_fast_T`.
  - contraction bwd: outgoing + incoming einsums (cuBLAS).
Shared back-half over the 2h concatenation (ln_out over 2h, to_out 2h->d, one gate).

### Blocker (documented, honest): fused dgrad_lnbwd does NOT apply at bidir LN dim K=2h=256
The v9 single-dir win folds LN_out+proj bwd into ONE tcgen05 dgrad epilogue (`dgrad_lnbwd_sm100`),
but its epilogue tile requires tile_n to cover K, and at K=256 quack's `make_smem_layout_a`
raises `Expected size in shape strictly positive, but got -1` (compile fail). v9 uses it at
K=128 only. So bidir training uses the SAFE fallback: cuBLAS `d_proj @ Wp.T` + the arch-agnostic
optimized LN_out bwd. `MINIWORLD_BIDIR_DGRAD_FUSED=1` re-attempts the fused path (currently fails).

## Correctness (bf16 fwd + per-grad vs fp32 pytorch bidir reference; randn input, random cotangent)
L=384 : fwd cos 0.999975 relmean 7.0e-3 ; WORST grad cos 0.999968 (all grads relmean 4.6-8.0e-3)
L=768 : fwd cos 0.999974 relmean 7.1e-3 ; WORST grad cos 0.999967
L=1024: fwd cos 0.999974 relmean 7.1e-3 ; WORST grad cos 0.999965
Per-grad relmean within ~2x bf16 floor, matching single-dir v9. PASS.
CUDA-graph fwd+bwd replay grads == eager: grad-cos 1.000000 at all L (graph time is honest).

## Verdict
cute bidir TRAINING (fwd+bwd) BEATS cuequiv on B200: 1.49-1.62x (graph, grad-cos-verified;
nsys true 1.62x @1024). Achieved WITHOUT the v9 dgrad-lnbwd fusion (unsupported at K=256).
